В эту папку засовываются библиотеки ManagedBASS.
Ссылка для скачивания:
https://www.un4seen.com/

Пути:
 - `libs/` - в эту папку засовывается библиотека для Windows x64_86 (`bass.dll`)
 - `libs/linux-arm64` - библиотека для arm64 (aarch64) Linux (`libbass.so`)
 - `libs/linux-x64` - библиотека для amd64 (x64_86) Linux (`libbass.so`)

 Если надо добавить библиотеки, см. `muzzstream.csproj`, там указаны пути, откуда брать библиотеки
